# SpeedSync Overlay — виджет 90 км/ч поверх других приложений

Нативное Android-приложение (Java, без сторонних библиотек). Работает в фоне,
ничего не показывает, пока скорость ниже 90 км/ч. При 90 км/ч и выше в правом
верхнем углу всплывает маленький виджет с обратным отсчётом **2:00**. Скорость
упала ниже 90 — виджет исчезает, счётчик сбрасывается; снова превысили — отсчёт
начинается заново.

## Почему это отдельное приложение, а не PWA

Виджет **поверх других приложений** (`SYSTEM_ALERT_WINDOW`) и работа в фоне
с GPS — это возможности Android SDK. Веб-приложение так не умеет, поэтому здесь
нативный foreground-сервис + overlay-окно.

## Как получить APK

### Вариант 1 — GitHub Actions (не нужен Android SDK на компьютере)

1. Создайте пустой репозиторий на GitHub.
2. Загрузите туда **содержимое этой папки** (не саму папку, а файлы внутри).
3. Откройте вкладку **Actions** → workflow **Build APK** → **Run workflow**.
4. Через 2–4 минуты в разделе **Artifacts** появится
   `SpeedSyncOverlay-debug-apk` — внутри `app-debug.apk`.

Сборка идёт на Ubuntu-раннере GitHub: JDK 17, Android SDK 34, Gradle 8.9.

### Вариант 2 — Android Studio

1. Android Studio (Koala или новее), JDK 17, Android SDK 34.
2. **Open** → выбрать папку проекта → дождаться синхронизации Gradle.
3. **Build → Build Bundle(s)/APK(s) → Build APK(s)**.
4. APK: `app/build/outputs/apk/debug/app-debug.apk`.

> APK отладочный (`debug`), подписан сам собой — для установки на планшет
> этого достаточно. Если нужен файл для Play Store, понадобится release-подпись.

## Установка на планшет

1. Перекиньте `app-debug.apk` на планшет (USB, облако, Telegram «себе»).
2. Откройте файл, разрешите установку из неизвестных источников.
3. В приложении по порядку:
   - **1. Разрешить геолокацию** — «При использовании приложения»;
   - **2. Разрешить поверх приложений** — включить переключатель;
   - **3. Разрешить уведомления** (Android 13+).
4. **Включить мониторинг** → свернуть приложение.
5. **Отключить оптимизацию батареи** — иначе прошивка может усыпить сервис.
6. Для планшета в машине: закрепить приложение и поставить на зарядку.

В шторке висит постоянное уведомление с кнопкой «Стоп» — это признак, что
мониторинг работает.

## Что внутри

```
app/src/main/java/ru/speedsync/overlay/
├── MainActivity.java   экран разрешений и кнопок
└── SpeedService.java   foreground-сервис: GPS, порог 90, overlay-виджет
```

Порог и длительность меняются в `SpeedService.java`:

```java
private static final float THRESHOLD_KMH = 90f;
private static final long COUNTDOWN_MS = 120_000L;
```

Разрешения в `AndroidManifest.xml`: `ACCESS_FINE_LOCATION`,
`FOREGROUND_SERVICE_LOCATION`, `SYSTEM_ALERT_WINDOW`, `POST_NOTIFICATIONS`.

## Ограничения

- **Геолокация должна быть включена** (GPS). В помещении виджет не появится:
  скорость берётся из `Location.getSpeed()`.
- Некоторые прошивки (Xiaomi, Huawei и т. п.) душат фоновые сервисы: помогает
  «Автозапуск», «Без ограничений» и отключение оптимизации батареи.
- Виджет показывается в правом верхнем углу с отступом 16 dp / 72 dp
  (чтобы не перекрывать строку состояния); положение меняется в
  `SpeedService.showOverlay()`.
- Проект не собирался на этой машине: здесь нет JDK/Android SDK и нет сети
  до `dl.google.com`. Сборка проверяется первым запуском GitHub Actions.
